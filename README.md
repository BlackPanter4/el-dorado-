# 🏜️ EL DORADO - Quantum Edition

> Juego didáctico, aventura y acción para iniciar el día.

Atraviesa 8 dunas, encuentra el mapa y abre el cofre de El Dorado. Cada nivel te da una clave poderosa generada con criptografía real.

### 🎮 Jugar ahora
👉 **https://blackpanter4.github.io/el-dorado-/**

### ✨ Características Quantum
- Sin imágenes que se traben - fondos con gradientes
- Contraseñas 100% seguras con `crypto.getRandomValues()`
- Vibración háptica y transiciones
- Instalable como App (PWA)
- Hecho para móvil
